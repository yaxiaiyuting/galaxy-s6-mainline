## 一、最终方案

**GNOME 43 内置屏幕键盘**（gnome-shell 的 `js/ui/keyboard.js`）

```sh

```

## 二、排障历程（两个被误判的真凶）

### 2.1 真凶一：两个 ibus-daemon 抢通道

```
2486 /usr/bin/ibus-daemon --panel disable   ← GNOME Shell 自己启动的
2512 /usr/bin/ibus-daemon -drx              ← 手动加的 autostart
```

两者抢同一套 D-Bus 输入法通道：
- GNOME 屏幕键盘的按键送到 `--panel` 那个
- 但 libpinyin 引擎挂在 `-drx` 那个下面

⇒ 按键被送到没有输入法的通道 → **吞字**

**修复**：删掉 `/root/.config/autostart/ibus.desktop`，
`pkill -f "ibus-daemon -drx"`，让 GNOME 启动唯一的 daemon。

### 2.2 真凶二：fontconfig 规则过宽导致「假吞字」

用户反馈的「吞字」有一部分其实是**终端字母间距异常大**。

根因：为修正简体中文字形，曾写过：

```xml
<match target="pattern">
  <test name="lang" compare="contains"><string>zh</string></test>
  <edit name="family" mode="prepend" binding="strong">
    <string>Noto Sans CJK SC</string>
  </edit>
</match>
```

系统 `LANG=zh_CN.UTF-8`，`fc-match` 默认带 `lang=zh`，
这条规则对**所有**字体请求生效 —— 包括 `DejaVu Sans Mono`。
结果终端用**比例** CJK 字体渲染拉丁字母，间距失真。

验证：
```
修复前: fc-match "DejaVu Sans Mono" → Noto Sans CJK SC   ❌
修复后: fc-match "DejaVu Sans Mono" → DejaVu Sans Mono   ✓
```

**修复**：所有规则加 `<test name="family" compare="eq">`，
精确限定到 generic family。

详见 `docs/中文本地化与插件-20261020.md`。

## 三、尝试过但放弃的方案

### 3.1 onboard

- 1.4.1 版，X11 时代设计
- Wayland 下用 `zwp_virtual_keyboard_v1` 注入按键
- 与 IBus 抢事件（虽然真实原因上面两个，但 onboard 本身也不是好选择）
- **已卸载**

### 3.2 maliit-keyboard

- 2.3.1，Qt/QML 实现，**自带 libpinyin 引擎**（依赖 `libpinyin15`）
- 有 `zh-hans` / `zh-hant` 语言插件
- 安装后配合 `qtwayland5` 能在 Wayland 下启动：
  ```
  maliit-server      ✓
  maliit-keyboard    ✓
  activeLanguage: zh-hans
  plugin ".../zh-hans/libzh-hansplugin.so" loaded
  ```

**放弃原因**：

1. **键盘窗口卡顿抽搐**
   maliit 是独立的 Qt 窗口，不是合成器的一部分。
   在 GNOME 下它和 mutter 的合成节奏对不上，持续重绘导致视觉抖动。

2. **无合成器级集成**
   GNOME 原生应用（GTK3/GTK4）走的是 `text-input-v3` 协议，
   不经过 Maliit 的 IM 插件，所以键盘不会在获得焦点时自动弹出。
   Maliit 是为 Phosh / Plasma Mobile / Lomiri 这类深度集成它的
   compositor 设计的。

**状态**：包保留（未卸载），autostart 已删除，进程已停。

### 3.3 squeekboard

- 未尝试。它是 Phosh 的键盘，同样需要 compositor 级
  `input-method` 协议支持，GNOME 下大概率有和 maliit 一样的问题。

## 四、GNOME 内置键盘的相关配置

### 4.1 libpinyin：关掉「拼音模式下直接打英文并补空格」

```sh
S=com.github.libpinyin.ibus-libpinyin.libpinyin
gsettings set $S english-input-mode false    # 拼音模式不再自动打英文
gsettings set $S english-candidate false     # 不显示英文候选
gsettings set $S auto-commit false
```

打英文时用 `Super+Space` 切到 `xkb-us` 输入源。

### 4.2 触发条件

- `screen-keyboard-enabled = true`
- 用**触摸**点进文本输入框（鼠标点击不会触发）
