# 避坑：点托盘切换输入法导致 GNOME Shell 崩溃

日期：2026-10-23
影响：GNOME Shell 43.9，ibus 1.5.27，Debian 12

---

## 现象

在终端里打开屏幕键盘（OSK）后，点击右上角托盘里的**输入法切换**按钮，
**整个桌面崩溃**（gnome-shell 退出，回到 GDM，所有窗口消失）。

journalctl 证据：

```
gnome-shell[155808]: JS ERROR: Error: GSettings schema
    org.freedesktop.ibus.engine.typing-booster not found
    _init@resource:///org/gnome/gjs/modules/core/overrides/Gio.js:709:23
    ...
    setCompletionEnabled@resource:///org/gnome/shell/misc/ibusManager.js:362:13
    _onDestroy@resource:///org/gnome/shell/ui/keyboard.js:1392:38
    _syncEnabled@resource:///org/gnome/shell/ui/keyboard.js:1237:28
```

另外 `coredumpctl list` 为空、无 OOM、内存充足（2.0Gi 可用）、
shell RSS 正常（215MB）⇒ **不是崩溃信号，是 JS 异常导致的干净退出**。

## 根因

GNOME Shell 43 的 `ui/keyboard.js` 在**屏幕键盘销毁**时
（`_onDestroy` → `_syncEnabled`）会调用
`ibusManager.setCompletionEnabled()`。

`misc/ibusManager.js` 里这个函数开头有：

```javascript
let settings = new Gio.Settings({schema_id: IBUS_TYPING_BOOSTER_SCHEMA});
// IBUS_TYPING_BOOSTER_SCHEMA = 'org.freedesktop.ibus.engine.typing-booster'
```

**如果系统没装 `ibus-typing-booster`，这个 schema 不存在 →
`new Gio.Settings()` 立刻抛异常。**
异常从 GObject 信号回调里逃出，GJS 无法捕获 → **gnome-shell 直接退出**。

（GNOME 自己的假设是"没装 typing-booster 时早返回"，但那段早返回代码
在函数更后面的分支里，schema 构造在其之前，所以保护没生效。
这是 GNOME Shell 43 的一个 bug，44+ 才修。）

## 修复

```sh
apt-get install -y ibus-typing-booster
```

安装后提供
`/usr/share/glib-2.0/schemas/org.freedesktop.ibus.engine.typing-booster.gschema.xml`，
`new Gio.Settings()` 不再抛异常。

验证：

```sh
gsettings list-schemas | grep typing
# org.freedesktop.ibus.engine.typing-booster
gsettings get org.freedesktop.ibus.engine.typing-booster emojipredictions
# false
ibus list-engine | grep typing
# typing-booster - Typing Booster
```

## 替代方案（不想装包时）

手写一个最小 stub schema 也能绕开：

```xml
<!-- /usr/share/glib-2.0/schemas/org.freedesktop.ibus.engine.typing-booster.gschema.xml -->
<schemalist>
  <schema id="org.freedesktop.ibus.engine.typing-booster" path="/org/freedesktop/ibus/engine/typing-booster/">
    <key name="emojipredictions" type="b"/>
    <key name="dictionary" type="s"/>
    <key name="inlinecompletion" type="b"/>
    <key name="inputmethod" type="s"/>
  </schema>
</schemalist>
```

然后 `glib-compile-schemas /usr/share/glib-2.0/schemas/`。
（但装了真包更简单，顺手还有输入预测功能。）
