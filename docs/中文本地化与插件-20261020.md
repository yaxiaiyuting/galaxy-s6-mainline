## 二、踩坑记录

### 2.1 apt 源在国内只有 8 KB/s

默认 `deb.debian.org` 实测 **8 KB/s**，装个 100MB 的
`fonts-noto-cjk` 要 3 小时。

实测各镜像：

| 镜像 | 速度 |
|---|---|
| mirrors.ustc.edu.cn | **372 KB/s** |
| mirrors.tuna.tsinghua.edu.cn | 264 KB/s |
| mirrors.aliyun.com | 211 KB/s |
| deb.debian.org | **52 KB/s** |

⇒ 改用阿里云/中科大源，速度提升 **50 倍**。
`apt update` 拉 31MB 从「几十分钟」变成 **75 秒**。

### 2.2 fonts-noto-cjk 太大，直接从未宿主机拷

宿主机（CachyOS）已装 Noto CJK，字体文件在
`/usr/share/fonts/noto-cjk/`：

```
NotoSansCJK-Regular.ttc   19 MB
NotoSansCJK-Bold.ttc      20 MB
```

直接 `scp` 到手机 `/usr/share/fonts/truetype/noto-cjk/`，
**LAN 传输 2.4 秒**，比下载快几百倍。

### 2.3 中文显示成日文字形（关键坑）

`NotoSansCJK-*.ttc` 是**集合字体**，一个文件里打包了
JP / SC / TC / HK / KR 五种字形。

fontconfig 默认按 family 名排序，会优先命中
`Noto Sans CJK JP`：

```sh
$ fc-match "sans:lang=zh-cn"
NotoSansCJK-Regular.ttc: "Noto Sans CJK JP" "Regular"   ← 错！
```

结果简体中文用**日文字形**渲染 —— 「直」「骨」「门」「关」等
字的写法都不对。

**修法**：加 `/etc/fonts/conf.d/99-g9209-zh-cn.conf`，
给 `lang` 含 `zh` 的 pattern 强制 prepend `Noto Sans CJK SC`：

```xml
<match target="pattern">
  <test name="lang" compare="contains"><string>zh</string></test>
  <edit name="family" mode="prepend" binding="strong">
    <string>Noto Sans CJK SC</string>
  </edit>
</match>
```

验证：
```sh
$ fc-match "sans:lang=zh-cn"
NotoSansCJK-Regular.ttc: "Noto Sans CJK SC" "Regular"   ✓
```

### 2.4 GNOME 插件装了但 CLI 不认识

`gnome-extensions enable xxx` 报「扩展不存在」——
因为新装的扩展目录要**重启 GNOME Shell** 才会被扫描。

**绕过方法**：直接用 gsettings 设置 `enabled-extensions` 列表：

```sh
gsettings set org.gnome.shell enabled-extensions \
  "['dash-to-dock@micxgx.gmail.com','ubuntu-appindicators@ubuntu.com',\
'hidetopbar@mathieu.bidon.ca','impatience@gfxmonk.net',\
'panel-osd@berend.de.schouwer.gmail.com']"
```
重启 GDM 后全部正常加载。

## 三、插件选择理由（手机场景）

| 插件 | 包名 | 用途 |
|---|---|---|
| **Dash to Dock** | `gnome-shell-extension-dashtodock` | 底部常驻 Dock，替代「活动」全屏切换，触屏友好 |
| **AppIndicator** | `gnome-shell-extension-appindicator` | 托盘图标（输入法、网络、电池等），GNOME 原生不支持 |
| **Hide Top Bar** | `gnome-shell-extension-autohidetopbar` | 自动隐藏顶栏，2K 手机屏上多出可观的垂直空间 |
| **Impatience** | `gnome-shell-extension-impatience` | **加速动画到 2 倍速**，Mali-T760 上体感明显更跟手 |
| **Panel OSD** | `gnome-shell-extension-panel-osd` | 通知位置可调，避免遮挡 |
| Extension Manager | `gnome-shell-extension-manager` | GUI 管理插件 |

**屏幕键盘 `onboard`**：手机上必需，否则没有物理键盘就没法输入文字。

## 四、验证命令

```sh
# 语言
localectl status | grep Locale
tr '\0' '\n' < /proc/$(pgrep -f 'gnome-shell$')/environ | grep LANG

# 字形（关键）
fc-match "sans:lang=zh-cn"     # 必须是 Noto Sans CJK SC

# 输入法
ibus list-engine | grep -i pinyin

# 插件
export XDG_RUNTIME_DIR=/run/user/0
export DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/0/bus
gnome-extensions list --enabled

# 会话类型（必须 wayland）
for S in $(loginctl list-sessions --no-legend | awk '{print $1}'); do
  loginctl show-session $S -p Type --value
done
pgrep Xorg   # 应该没有输出
```
